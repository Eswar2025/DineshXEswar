# DOM Practice – Greeting Card

You are given a page with a heading, a paragraph and two buttons (`index.html` + `style.css`).
Write the JavaScript in `script.js` so the page behaves like this:

## Tasks

1. When **"Change Text"** is clicked, the heading text should become `Hello, DOM!`.
2. When **"Change Text"** is clicked, the paragraph text should become `I changed this with JavaScript.`
3. When **"Make It Pretty"** is clicked, the heading colour should become `tomato`.
4. When **"Make It Pretty"** is clicked, the box (`#card`) should get the CSS class `highlight` (already written in `style.css`).

## Bonus (only after 1–4 work)

5. Clicking **"Make It Pretty"** a second time should remove the `highlight` class again (so it switches on and off).

## How to check

Open `index.html` in the browser. Click each button and see if it matches the tasks above.
Stuck? Look in `Hints.md`, but try on your own first.
