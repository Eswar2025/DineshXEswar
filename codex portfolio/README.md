# Codex Portfolio Clone

This is a static basic clone of `https://shajith-portfolio-seven.vercel.app/`.

## Files

- `index.html` - page structure
- `styles.css` - visual styling and responsive layout
- `script.js` - panel toggles, theme switch, carousel controls, and command search
- `assets/shajith-photo.jpeg` - public profile photo from the original site

## Open

Open `index.html` in a browser.
