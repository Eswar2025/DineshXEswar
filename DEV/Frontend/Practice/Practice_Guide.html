How to practice

Start with Quiz room and work through the sequence. These exercises test independent implementation, not just visual copying.

Repeat this workflow for each question

  1. Read the brief, behavior rules, and exact test cases.
  2. Open all three SVGs. Sketch the page’s layout and the data you need.
  3. Create your own files inside that question’s solution/ folder. Build the static interface with HTML/CSS first.
  4. Add one interaction at a time. Update your state, then render the result.
  5. Verify normal, invalid, empty, and saved states before checking a requirement.
  6. Explain the code and do one small change in front of Dinesh.

The SVGs are static visual targets, not app components or finished solutions. Build real controls. Do not use an SVG as a screenshot substitute for the interface.

Ground rules and effort

Build all four with pure HTML, CSS, and JavaScript. You can look up concepts and syntax while writing your own implementation.

Scope and resources

  • Write the app using only HTML, CSS, and plain JavaScript. No React, Tailwind, Bootstrap, UI kits, copied templates, or AI-generated implementation.
  • Use actual forms, buttons, labels, and appropriate semantic elements. A placeholder is not a label. Use addEventListener rather than inline event attributes.
  • Make it work at 1200px desktop and 390px phone width without horizontal page overflow. Match layout, hierarchy, spacing, and states; system-font differences are acceptable.
  • Use visible keyboard focus, logical tab order, and text for success/errors. Render user-entered text as text, so markup typed into a field is displayed literally.
  • Make every core control work. Extra decoration does not replace missing behavior. Keep the browser console free of app errors.
  • AI is allowed for concepts, syntax, decisions, or a small hint about your own attempt. Eswar writes the HTML, CSS, JavaScript, and fixes himself.

Plan your sessions

Core estimates total 21–29 hours. Allow another 4–6 hours for visual polish and peer reviews: roughly 25–35 focused hours. New concepts can take longer. These are estimates, not deadlines.

Open Question.html and the SVGs locally in a browser. You can use a small local development server for your own solution; that is recommended for consistent storage behavior. Browser behavior for localStorage on file URLs is not guaranteed. The guide handles unavailable storage and supports progress export/import.

Each exercise guide stores its own manual checks and notes. Those are separate from the localStorage data you implement in your own app. Use a different app key for each solution.
